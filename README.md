# E Commerce Responsive Web
As a final project (individual) for Human & Computer Interaction course, this project focuses on evaluating my skills to create a proper Figma prototype, and how well can i translate the prototypes into raw html instead of building a fully functional web.  
[Figma](https://drive.google.com/drive/folders/1h_T309ejkBtaon9yMfe98Ni7H25gWAgF?usp=sharing](https://www.figma.com/proto/QRPFp5KikIjjqdbM0SCDvF/hitoyz?node-id=70-1446&t=3uiKVYByhooaEKee-0&scaling=min-zoom&content-scaling=fixed&page-id=0%3A1&starting-point-node-id=3%3A5)).
[Website Demo](https://drive.google.com/file/d/1abJLWtuBdg41iiqt6VqbI0RFBORENkqH/view?usp=sharing)).
### Features
- Navigation Bar
- Search Bar
- Register Buttons
- Horizontal Scroll section for Banners
- E-commerce Product Display with Categories
- Footer with Logo and Hyperlinks
- Responsiveness
- 90% Figma to HTML translation
