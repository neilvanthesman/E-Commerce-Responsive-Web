# E Commerce Responsive Web
As a final project (individual) for Human & Computer Interaction course, this project focuses on evaluating my skills to create a proper Figma prototype, and how well can i translate the prototypes into raw html website.  
### Features
- Navigation Bar
- Search Bar
- Login & Register Buttons
- Carousel Section for Banners
- E-commerce Product Display with Categories
- Footer with Logo and Hyperlinks
- Fully Responsive Layout
- Custom CSS Styling

### Installation

```
cd indotrade
npm install
npm run dev
```
